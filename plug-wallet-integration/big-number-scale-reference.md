## The rule

- Every naming level after Thousand adds exactly **3 more zeros** (×10³ per level).
- Zeros = the power-of-ten exponent. For the Latin-numbered names (Million = 1 …
  Decillion = 10, Undecillion = 11 … Unvigintillion = 21): **exponent = 3 × (n + 1)**.
